# 다양한 전략패턴
---
### 템플릿/콜백 패턴

- 템플릿/콜백 패턴(Template/Callback Pattern)은 변하지 않는 공통 로직(템플릿)과 매번 달라지는 로직(콜백)을 분리하여 코드 중복을 제거하는 패턴이다.

- 탬플릿(template) : 어떤 목적을 위해 미리 만들어둔 모양이 있는 틀(변하지 않는 공통 로직)

- 콜백(callback) : 실행되는 것을 목적으로 다른 오브젝트의 메소드에 전달되는 오브젝트(탬플릿이 실행중에 호출하는 변경가능한 로직)

- 아래 코드 처럼 SQL마다 클래스를 하나씩 만들어야 한다는 점을 극복하기 위해 탬플릿/콜백 패턴을 고안 

```java
public interface StatementStrategy {
    PreparedStatement makePreparedStatement(
            Connection c) throws SQLException;
}

public class DeleteAllStatement
        implements StatementStrategy {

    @Override
    public PreparedStatement makePreparedStatement(
            Connection c) throws SQLException {

        return c.prepareStatement(
                "delete from users");
    }
}
```
- 변경완료

```java
jdbcContext.workWithStatementStrategy(
    new StatementStrategy() {
        @Override
        public PreparedStatement makePreparedStatement(
                Connection c)
                throws SQLException {

            return c.prepareStatement(
                    "delete from users");
        }
    }
);
```
