# 추상 메서드 vs 인터페이스 vs Enum 정리

------------------------------------------------------------------------

## 1. 추상 클래스 vs 인터페이스

### ✔ 추상 클래스 (Abstract Class)

-   일부 구현 + 일부 미구현 제공
-   `abstract` 키워드 사용
-   단일 상속만 가능 (`extends`)
-   필드(변수) 선언 가능
-   일반 메서드 + 추상 메서드 함께 사용 가능

``` java
abstract class Animal {
    abstract void sound(); // 추상 메서드

    void eat() {
        System.out.println("먹는다");
    }
}
```

------------------------------------------------------------------------

### ✔ 인터페이스 (Interface)

-   기능의 규약(명세) 정의
-   `interface` 키워드 사용
-   다중 구현 가능 (`implements`)
-   메서드는 기본적으로 `public abstract`
-   변수는 `public static final` (상수만 가능)
-   Java 8 이후 `default`, `static` 메서드 사용 가능

``` java
interface Animal {
    void sound(); // public abstract 자동
}
```

------------------------------------------------------------------------

## 2. 추상 메서드 특징

-   `abstract` 키워드 사용
-   메서드 몸체 없음 (`{}` 없음)
-   반드시 자식 클래스에서 구현해야 함
-   ❌ `final`과 함께 사용 불가능 (충돌 발생)

------------------------------------------------------------------------

## 3. 인터페이스 특징

-   모든 메서드는 기본적으로 `public abstract`
-   모든 변수는 `public static final`
-   다중 구현 가능
-   `default` 메서드로 일부 구현 가능
-   ❌ 일반 필드(변수) 선언 불가능

------------------------------------------------------------------------

## 4. 핵심 차이

  구분     추상 클래스                  인터페이스
  -------- ---------------------------- ------------------------------
  목적     공통 기능 + 일부 구현 제공   기능 규약 정의
  상속     단일 상속                    다중 구현
  키워드   `abstract`                   `interface`
  메서드   일반 + 추상 메서드 가능      기본 abstract (default 가능)
  변수     일반 변수 가능               상수만 가능
  관계     IS-A 관계                    CAN-DO 관계

------------------------------------------------------------------------

## 5. Enum (열거형)

### ✔ 개념

-   고정된 상수 집합을 표현하는 타입
-   문자열/숫자보다 타입 안정성이 높음

``` java
enum Status {
    READY, RUNNING, DONE
}
```

------------------------------------------------------------------------

### ✔ 특징

-   컴파일 시 타입 안전성 보장
-   `switch`문 사용 가능
-   클래스처럼 필드, 생성자, 메서드 정의 가능

------------------------------------------------------------------------

### ✔ 확장 예시

``` java
enum Status {
    READY("준비"),
    RUNNING("실행"),
    DONE("완료");

    private String description;

    Status(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }
}
```

------------------------------------------------------------------------

## 6. 한 줄 요약

-   추상 클래스 → **공통 기능 + 일부 구현 제공**
-   인터페이스 → **기능 규약 정의**
-   Enum → **고정된 값 집합을 타입으로 관리**
