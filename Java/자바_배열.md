# 📌 Java 배열(Array) 핵심 정리

## 🔹 배열이란?

-   하나의 변수에 여러 개의 값을 저장하는 자료구조
-   같은 타입의 데이터만 저장 가능
-   인덱스(index)는 0부터 시작

------------------------------------------------------------------------

## 🔹 배열 선언 및 생성

### 1차원 배열Q

``` java
int[] lottoNumber = new int[7];
```

### 2차원 배열

``` java
int[][] twoDim = new int[2][3];
```

------------------------------------------------------------------------

## 🔹 배열 선언 방식

``` java
int[] arr;   // 권장
int arr[];   // 비권장
```

------------------------------------------------------------------------

## 🔹 배열 초기화

``` java
int[] arr = {1, 2, 3};
int[] arr2 = new int[]{1, 2, 3};
```

------------------------------------------------------------------------

## 🔹 배열 기본값

-   int → 0
-   double → 0.0
-   boolean → false
-   char → '`\u0`{=tex}000'
-   String → null

------------------------------------------------------------------------

## 🔹 배열 길이

``` java
arr.length
```

------------------------------------------------------------------------

## 🔹 예외

### ArrayIndexOutOfBoundsException

``` java
int[] arr = {1,2,3};
System.out.println(arr[3]); // 오류
```

------------------------------------------------------------------------

## 🔹 반복문

### 기본 for

``` java
for(int i=0;i<arr.length;i++){
    System.out.println(arr[i]);
}
```

### 향상된 for

``` java
for(int num : arr){
    System.out.println(num);
}
```

------------------------------------------------------------------------

## 🔹 배열 복사

### 얕은 복사

``` java
int[] arr2 = arr1;
```

### 깊은 복사

``` java
int[] arr2 = new int[arr1.length];
System.arraycopy(arr1, 0, arr2, 0, arr1.length);
```

------------------------------------------------------------------------

## 🔹 배열 정렬

``` java
Arrays.sort(arr);
```

------------------------------------------------------------------------

## 🔹 배열 출력

``` java
System.out.println(Arrays.toString(arr));
```

------------------------------------------------------------------------

## 🔹 main 메서드

``` java
public static void main(String[] args)
```

-   실행 인자는 공백 기준 전달
-   모두 문자열(String)

``` java
int num = Integer.parseInt(args[0]);
```

------------------------------------------------------------------------

## 🔥 핵심 요약

-   배열: 같은 타입 데이터 집합
-   인덱스: 0부터 시작
-   길이: length
-   예외: ArrayIndexOutOfBoundsException
-   반복문: for / for-each
