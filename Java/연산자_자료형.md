# Java 자료형 `byte`

## 1. byte란?

`byte`는 Java의 기본 자료형(Primitive Type) 중 하나로, **정수를 저장하는 1바이트 크기의 자료형**입니다.  
메모리를 적게 사용하기 때문에, 작은 범위의 숫자를 저장할 때 사용할 수 있습니다.

---

## 2. 크기와 범위

- 크기: **1 byte (8bit)**
- 표현 범위: **-128 ~ 127**

즉, `byte`는 총 256개의 값을 표현할 수 있습니다.

```java
byte a = 10;
byte b = -128;
byte c = 127;
```

---

## 3. 선언 방법

```java
byte num;
num = 100;
```

또는 선언과 동시에 초기화할 수도 있습니다.

```java
byte num = 50;
```

---

## 4. byte 사용 예시

```java
public class Main {
    public static void main(String[] args) {
        byte age = 25;
        byte temperature = -10;

        System.out.println(age);
        System.out.println(temperature);
    }
}
```

---

## 5. 주의할 점

### 5-1. 범위를 벗어나면 오류 발생

`byte`는 -128 ~ 127까지만 저장할 수 있으므로, 범위를 벗어난 값을 넣으면 컴파일 오류가 발생합니다.

```java
byte num = 128; // 오류 발생
```

---

### 5-2. 연산 시 `int`로 자동 변환됨

Java에서는 `byte`끼리 연산하더라도 결과가 `int`로 처리됩니다.

```java
byte a = 10;
byte b = 20;
// byte c = a + b; // 오류
int c = a + b;     // 가능
```

따라서 다시 `byte`에 저장하려면 형변환이 필요합니다.

```java
byte c = (byte)(a + b);
```

---

## 6. 언제 사용할까?

`byte`는 아래와 같은 경우에 사용할 수 있습니다.

- 저장 값의 범위가 매우 작을 때
- 메모리 사용량을 줄이고 싶을 때
- 파일, 네트워크, 바이너리 데이터 처리 시
- 이미지, 오디오, 패킷 데이터 등 바이트 단위 처리가 필요할 때

다만 일반적인 정수 계산에서는 보통 `int`를 더 많이 사용합니다.

---

## 7. byte와 다른 정수형 비교

| 자료형 | 크기 | 범위 |
|---|---:|---:|
| `byte` | 1 byte | -128 ~ 127 |
| `short` | 2 byte | -32,768 ~ 32,767 |
| `int` | 4 byte | 약 -21억 ~ 21억 |
| `long` | 8 byte | 매우 큰 정수 범위 |

---

## 8. 정리

- `byte`는 **1바이트 크기의 정수형**
- 범위는 **-128 ~ 127**
- 작은 숫자를 저장할 때 사용 가능
- 연산 시 자동으로 `int`로 변환되는 점을 주의해야 함

---

## 9. 한 줄 요약

> `byte`는 Java에서 가장 작은 정수형 자료형이며, 메모리를 적게 사용하지만 표현 범위가 매우 작습니다.
