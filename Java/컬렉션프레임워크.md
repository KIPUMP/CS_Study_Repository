## 주요 인터페이스

### List
- 순서 O / 중복 O
- ArrayList, Vector(Stack의 부모), LinkedList 존재


### Set
- 순서 X / 중복 X
- HashSet, TreeSet 존재
- 원소 추가 : add(Object o), addAll(Collection<E>)


### Queue
- FIFO 구조
- Deque(덱), PriorityQueue(우선순위 큐) 존재

### Map
- Key-Value 구조

---

## List<E> 추가 개념

### 1. 주어진 인덱스에 데이터 추가
→ add(int index, Object element)

### 2. 주어진 인덱스에 데이터 존재 확인
→ get(int index)

### 3. 지정된 객체의 위치(중복시 첫번째 원소의 인덱스) 반환
→ indexOf(Object o)

### 4. 지정된 객체의 위치(중복시 마지막 원소의 인덱스) 반환
→ LastIndexOf(Object o)

### 5. 주어진 객체 삭제
→ remove(Object o)

### 6. List 객체 정렬
→ Collections.sort(List<E>)
