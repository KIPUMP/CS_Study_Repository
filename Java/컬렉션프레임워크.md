# Java Collection Framework 정리 

## 📌 컬렉션 프레임워크 핵심 요약
- 여러 데이터를 하나의 객체로 관리하기 위한 API
- 인터페이스 기반 설계 → 확장성과 재사용성 ↑

---

## 📌 기본 구조
Iterable
   └── Collection
         ├── List
         ├── Set
         └── Queue
Map (Collection 계열 아님)

---

## 📌 주요 인터페이스

### List
- 순서 O / 중복 O

### Set
- 순서 X / 중복 X

### Queue
- FIFO 구조

### Map
- Key-Value 구조

---

## ✅ 추가 개념

### 1. 순서와 상관없이 여러 데이터를 하나의 객체에 저장하는 인터페이스
→ Set

### 2. HashSet 초기 사이즈 지정 가능 여부
→ 가능

### 3. 데이터 추가
→ add()

### 4. 데이터 존재 확인
→ contains()

### 5. 데이터 삭제
→ remove()
