# 📌 변수 (Variable)

---

## 1️⃣ 정의
- 프로그램에서 데이터를 저장하기 위한 공간
- 값을 담기 위해 사용하는 이름 있는 저장소

👉 변수는 반드시 **이름(식별자)** 을 가져야 한다

---

# 📌 자바 변수의 종류

---

## 1️⃣ 지역 변수 (Local Variable)
- 중괄호 `{}` 내부에서 선언된 변수

### ✔ 특징
- 선언된 블록 내에서만 사용 가능

### ✔ 생명주기
- 블록 시작 → 생성
- 블록 종료 → 소멸

---

## 2️⃣ 매개변수 (Parameter)
- 메소드 호출 시 전달되는 변수

### ✔ 특징
- 메소드 내부에서만 사용

### ✔ 생명주기
- 메소드 호출 시 생성
- 메소드 종료 시 소멸

---

## 3️⃣ 인스턴스 변수 (Instance Variable)
- 클래스 내부, 메소드 외부에 선언된 변수
- `static` 키워드가 없음

### ✔ 특징
- 객체마다 별도로 존재

### ✔ 생명주기
- 객체 생성 시 생성
- 객체가 더 이상 참조되지 않으면 소멸

---

## 4️⃣ 클래스 변수 (Class Variable)
- 클래스 내부, 메소드 외부에 선언된 변수
- `static` 키워드 사용

### ✔ 특징
- 모든 객체가 공유

### ✔ 생명주기
- 클래스 로딩 시 생성
- 프로그램 종료 시 소멸

---

## 5️⃣ 인스턴스 변수 예시

```java
public class Car {
    int speed;
    int distance;
    String color;
}

# 📌 변수 생명주기 정리

| 변수 종류 | 생성 시점 | 소멸 시점 |
|----------|----------|----------|
| 지역 변수 | 블록 시작 | 블록 종료 |
| 매개변수 | 메소드 호출 | 메소드 종료 |
| 인스턴스 변수 | 객체 생성 | GC 대상 |
| 클래스 변수 | 클래스 로딩 | 프로그램 종료 |

👉 변수 종류에 따라 **사용 범위와 생명주기**가 다르다


# 📌 메모리 관리 (Java vs C/C++)

---

## ✔ C / C++
- 개발자가 직접 메모리 할당 및 해제
- malloc, free 사용

---

## ✔ Java
- 가비지 컬렉터(Garbage Collector)가 자동으로 메모리 관리
- 더 이상 참조되지 않는 객체를 자동으로 제거

👉 개발자가 직접 메모리 해제할 필요 없음

# 📌 자바 자료형 (Data Type)

---

## 1️⃣ 기본 자료형 (Primitive Type)
- 실제 값을 직접 저장
- 예: int, char, double, boolean

---

## 2️⃣ 참조 자료형 (Reference Type)
- 객체의 주소(참조값)를 저장
- 예: String, 배열, 객체

---

## ✔ 차이점

| 구분 | 기본 자료형 | 참조 자료형 |
|------|------------|------------|
| 저장 값 | 실제 값 | 주소 |
| 메모리 | Stack | Heap |
