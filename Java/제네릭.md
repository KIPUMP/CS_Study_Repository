# ☕ Java 제네릭(Generic) 정리

## 1. 제네릭이란?

제네릭(Generic)은 **클래스나 메소드에서 사용할 데이터 타입을 나중에
결정하는 기법**이다.

> ✔ 선언 시점이 아니라 **사용 시점(객체 생성 / 메소드 호출 시점)**에
> 타입을 확정한다.

------------------------------------------------------------------------

## 2. 제네릭의 장점

### 타입 안정성 (Type Safety)

-   잘못된 타입을 컴파일 단계에서 방지
-   형변환 필요 없음

### 코드 간결성

-   불필요한 캐스팅 제거
-   가독성 향상

------------------------------------------------------------------------

## 3. 제네릭 클래스

``` java
public class Box<M, I> {
    private M material;
    private I item;

    public M getMaterial() { return material; }
    public I getItem() { return item; }

    public void setMaterial(M material) { this.material = material; }
    public void setItem(I item) { this.item = item; }
}
```

### 특징

-   클래스 전체에서 사용 가능 (전역 느낌)

------------------------------------------------------------------------

## 4. 제네릭 메소드

``` java
public class CoffeeMachine {
    public <T> Coffee makeCoffee(T capsule) {
        return new Coffee(capsule);
    }
}
```

### 특징

-   해당 메소드 내부에서만 사용 (지역 느낌)

------------------------------------------------------------------------

## 5. 클래스 vs 메소드 제네릭

-   클래스 제네릭 → 클래스 전체
-   메소드 제네릭 → 메소드 내부

------------------------------------------------------------------------

## 6. 핵심 정리

-   제네릭 = 타입을 나중에 결정
-   클래스 제네릭 = 전역 느낌
-   메소드 제네릭 = 지역 느낌
