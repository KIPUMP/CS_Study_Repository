# Java 핵심 정리

## 메소드 오버로딩과 오버라이딩

### 메소드 오버로딩 (Overloading)

#### 개념
같은 이름의 메소드를 여러 개 정의하되, **매개변수의 타입, 개수, 순서**를 다르게 하는 것입니다.

#### 조건
- 메소드 이름이 같아야 함
- 매개변수 타입 / 개수 / 순서가 달라야 함
- 반환 타입만 다른 것은 허용되지 않음

#### 예시
```java
public class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

#### 특징
- 컴파일 시점에 결정됨
- 정적 바인딩(Static Binding)
- 같은 클래스 내에서 주로 사용

#### 한 줄 정리
**이름은 같고, 파라미터로 구분하는 것이 오버로딩입니다.**

---

### 메소드 오버라이딩 (Overriding)

#### 개념
부모 클래스의 메소드를 자식 클래스에서 **재정의**하는 것입니다.

#### 조건
- 메소드 이름이 같아야 함
- 매개변수가 같아야 함
- 반환 타입이 같아야 함(또는 하위 타입)
- 접근제어자는 부모보다 더 좁아질 수 없음
- `@Override` 사용 권장

#### 예시
```java
class Animal {
    void sound() {
        System.out.println("동물 소리");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("멍멍");
    }
}
```

#### 특징
- 실행 시점에 결정됨
- 동적 바인딩(Dynamic Binding)
- 다형성의 핵심 개념

#### 한 줄 정리
**부모의 메소드를 자식이 다시 정의하는 것이 오버라이딩입니다.**

---

### 오버로딩 vs 오버라이딩 비교

| 구분 | 오버로딩 | 오버라이딩 |
|------|----------|------------|
| 정의 | 같은 이름, 다른 파라미터 | 부모 메소드 재정의 |
| 위치 | 같은 클래스 | 상속 관계 |
| 결정 시점 | 컴파일 시점 | 실행 시점 |
| 파라미터 | 달라야 함 | 같아야 함 |
| 반환 타입 | 자유 | 동일 또는 하위 타입 |
| 다형성 | 직접적 관련 적음 | 핵심 개념 |

#### 면접용 한 줄
“오버로딩은 컴파일 시점에 메소드가 결정되는 정적 바인딩이고, 오버라이딩은 실행 시점에 결정되는 동적 바인딩으로 다형성을 구현할 때 사용됩니다.”
**오버로딩은 같은 이름의 메소드를 매개변수로 구분하는 것이고, 오버라이딩은 상속 관계에서 부모 메소드를 재정의하는 것입니다.**

#### 정리
- **오버로딩**: 같은 이름 + 다른 파라미터
- **오버라이딩**: 부모 메소드 재정의
