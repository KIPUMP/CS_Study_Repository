# 📌 클래스 (Class)

---

## 1️⃣ 정의
- 객체를 생성하기 위한 설계도
- 변수(속성)와 메소드(기능)를 포함하는 사용자 정의 자료형

---

## 2️⃣ 특징
- Java의 기본 단위
- `public class 클래스명` 형태로 선언
- 상태(State)와 행동(Behavior)을 포함해야 함

---

## 3️⃣ 구성 요소

### ✔ 속성 (Field / Variable)
- 객체의 상태를 나타내는 값

### ✔ 메소드 (Method)
- 객체의 동작(기능)을 수행

---

# 📌 메소드 (Method)

---

## 1️⃣ 정의
- 클래스 내부에서 특정 기능을 수행하는 함수

---

## 2️⃣ 특징
- 메소드 이름 뒤의 소괄호 `()` 안에 매개변수 작성
- 메소드 이름 앞에는 반환 타입(Return Type) 명시
- 결과를 반환할 때 `return` 사용

---

## 3️⃣ 기본 구조
```java
returnType methodName(parameter) {
    // 기능 수행
    return 값;
}
